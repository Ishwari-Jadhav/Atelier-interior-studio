# Atelier Design Studio — Landing Page

A modern, minimalist, luxury interior design studio landing page built with semantic HTML5 and Tailwind CSS.

---

## 🎨 Design System & Palette

- **Primary Canvas Background**: `#FDFBF7` (Warm off-white / beige)
- **Primary Typography**: `#1F1F1F` (Deep Charcoal)
- **Terracotta Accents**: `#C27A56` (Deep Terracotta), `#A35E3B` (Terracotta Dark), `#DFC2B1` (Warm Terracotta Tint)
- **Stone Accents**: `#ECE5DA` (Warm Stone Surface), `#F8F4EC` (Light Stone Card), `#E4DDD2` (Stone Borders)
- **Typography Pairing**:
  - Headings / Editorial: *Cormorant Garamond* & *Cinzel* (Google Fonts)
  - Body / Navigation / UI: *Plus Jakarta Sans*

---

## ✨ Features Included

1. **Sticky Glassmorphism Navbar**:
   - Brand name: *Atelier Design Studio* with refined serif typography.
   - Smooth navigation links (*About*, *Portfolio*, *Services*, *Contact*).
   - "Get in Touch" pill button with micro-interactions.
   - Fully responsive hamburger navigation drawer for mobile screens.

2. **Hero Section**:
   - Bold editorial serif headline: *"Sculpting spaces of quiet luxury and enduring poise."*
   - Editorial subheading detailing studio vision.
   - Primary and secondary Call-to-Action buttons.
   - Editorial photography showcase with floating accolade badge (*"AD Top 50 Studios"*) and studio metric counters (15+ Years, 120+ Sanctuaries, 18 Design Honors).

3. **Philosophy / Ethos Section**:
   - Storytelling on organic stillness, tactile materials, and circadian illumination.

4. **Services Section**:
   - Clean 3-column luxury card grid:
     1. *Interior Architecture & Spatial Planning*
     2. *Bespoke Furnishing & Art Curation*
     3. *Turnkey Execution & White-Glove Handover*
   - Editorial numbered markers (`01`, `02`, `03`), clean iconography, bulleted deliverables, and hover elevation.

5. **Portfolio Showcase**:
   - Responsive grid showcasing architectural photography via Unsplash.
   - Interactive category filter tabs (*All Works*, *Residential*, *Hospitality*, *Penthouses*).
   - Interactive project detail modal/lightbox with project specs, materiality tags, and full-resolution imagery.

6. **Consultation Inquiry Form**:
   - Luxury input fields for **Full Name**, **Email Address**, **Phone Number**, and **Project Budget dropdown**.
   - Additional architectural vision / location field.
   - Interactive client-side validation, loading spinner state, and success confirmation screen.

7. **Footer**:
   - Studio manifesto & global presence (*New York · Paris · Milan*).
   - Full physical addresses with phone numbers and email links.
   - Working social media SVGs (Instagram, Pinterest, LinkedIn, ArchDaily).
   - Quarterly journal subscription field.
   - Copyright and legal credentials.

---

## 🚀 How to Run & Preview

You can open `index.html` directly in any web browser, or serve it locally with:

```bash
# Using Python
python -m http.server 8000

# Or using npx serve
npx serve .
```

Then visit `http://localhost:8000` in your browser.
